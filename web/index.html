About This Demo

This demo uses ONNX Runtime Web to run neural networks trained in Rust entirely in your browser. The models were trained in Rust, exported to ONNX format, and loaded client-side. No server-side processing is required - all inference happens locally using WebAssembly and WebGL acceleration.

Key Features: • ONNX Runtime Web for inference • WebAssembly + WebGL acceleration • Models trained in Rust, exported to ONNX • No server communication required • Industry-standard ONNX format
