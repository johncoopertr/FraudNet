About This Demo

This demo runs trained neural networks entirely in your web browser using JavaScript. The models were trained in Rust and exported to JSON format. No server-side processing is required - all inference happens locally on your device.

Key Features: • Pure client-side inference • No server communication required • Trained models serialized to JSON • ReLU activation for hidden layers • Sigmoid activation for output layer
